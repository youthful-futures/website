# Youthful Futures — website

Single-page landing site. Static HTML/CSS, no dependencies.

- Edit copy in `src/index.html`, then run `python3 build.py` to regenerate `index.html` (it inlines the Open paths artwork into the hero).
- Styles: `assets/style.css` (brand colours and Manrope from the identity kit).
- Preview: `python3 -m http.server` and open http://localhost:8000.

Before launch:
- **People**: replace the four placeholder cards in the People section (search for `is-placeholder`). Add consented photos at `assets/img/people/` (4:5), names, roles and profile links.
- **Contact**: add the approved address in Connect (search for `Contact details coming soon`).
- **Partners**: Tvarita Arts Collective is credited for the art wing only; add other partners once agreed.
