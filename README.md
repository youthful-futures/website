# Youthful Futures — website

Single-page landing site. Static HTML/CSS, no dependencies.

- Edit copy in `src/index.html`, then run `python3 build.py` to regenerate `index.html` (it inlines the Open paths artwork so the hero lines animate).
- Styles: `assets/style.css` (brand colours and Manrope from the identity kit).
- Preview: `python3 -m http.server` and open http://localhost:8000.

Before launch: add the approved contact route in the Get involved section (search for `Contact details coming soon`).
